====================================================================
        PHARMAI - DEPLOYMENT ON RENDER (FREE TIER, AUTO-DEPLOY)
====================================================================

The app has two parts. Both are FREE Render "Web Services" connected to the
same GitHub repository, and both redeploy automatically on every git push.

  1. pharmaimedication  (already exists)  Node website + OCR
                        https://pharmaimedication.onrender.com
  2. pharmai-ml         (create once)     Python ML models

--------------------------------------------------------------------
STEP 1: PUSH THE CODE (from the project folder)
--------------------------------------------------------------------
  git add -A
  git commit -m "Real OCR, retrained ML models, Python ML service"
  git push

  The existing "pharmaimedication" service redeploys by itself.
  (Render dashboard > pharmaimedication > Settings: Build Command
   "npm install && npm run build", Start Command "npm start" - keep them.)

--------------------------------------------------------------------
STEP 2: CREATE THE ML SERVICE (only once)
--------------------------------------------------------------------
  Render dashboard > "New +" > "Web Service" > choose the same
  "pharmaimedication" GitHub repository, then fill in:

    Name            : pharmai-ml
    Branch          : main
    Root Directory  : (leave empty)
    Runtime         : Python 3
    Build Command   : pip install -r backend/requirements.txt
    Start Command   : uvicorn backend.main:app --host 0.0.0.0 --port $PORT
    Instance Type   : Free
    Environment variable:  PYTHON_VERSION = 3.11.9
    Advanced > Health Check Path : /health
    Advanced > Auto-Deploy       : Yes (default)

  Click "Create Web Service" and wait until it says "Live" (5-10 min).
  Copy its URL, e.g.  https://pharmai-ml.onrender.com
  Check:  https://pharmai-ml.onrender.com/health  -> {"status":"healthy",...}

--------------------------------------------------------------------
STEP 3: CONNECT THE WEBSITE TO THE ML SERVICE (only once)
--------------------------------------------------------------------
  Render dashboard > pharmaimedication > Environment > Add variable:

    ML_API_URL = https://pharmai-ml.onrender.com     (your URL from step 2)

  Also make sure NODE_ENV = production is set. Save -> it redeploys.

  Check:  https://pharmaimedication.onrender.com/api/health
          -> {"web":"ok","ml":"ok", ...}

--------------------------------------------------------------------
AFTER THAT
--------------------------------------------------------------------
  Every "git push" to main redeploys BOTH services automatically.
  No API keys are needed.

  Free services sleep after 15 minutes without visitors. Opening the
  website also wakes the ML service; the first analysis after a long
  pause can take about 1 minute. Before a demo, open
  https://pharmaimedication.onrender.com/api/health once and wait
  until it shows "ml":"ok".
